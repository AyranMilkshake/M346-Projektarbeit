# Public Cloud

## Definition

Bei der Public Cloud wird die IT-Infrastruktur (Server, Speicher, Netzwerk) von einem grossen Anbieter betrieben und über das Internet **öffentlich für jeden** zugänglich gemacht. Mehrere Kunden teilen sich dieselbe physische Hardware im Hintergrund (Multi-Tenant), sind aber logisch strikt voneinander getrennt.

Man "mietet" sich also einen Teil der Rechenleistung eines riesigen, gemeinsam genutzten Rechenzentrums.

## Eigenschaften

- Keine eigene Hardware nötig, alles wird vom Anbieter betrieben
- Sehr hohe Skalierbarkeit – praktisch unbegrenzte Ressourcen verfügbar
- Kosten nach Nutzung (Pay-as-you-go), keine hohen Anfangsinvestitionen
- Ressourcen werden mit anderen Kunden geteilt (Multi-Tenant-Architektur)
- Weniger Kontrolle über physischen Standort der Daten

## Beispiele

- Microsoft Azure
- Amazon Web Services (AWS)
- Google Cloud Platform
