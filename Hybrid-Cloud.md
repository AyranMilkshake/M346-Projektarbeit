# Hybrid Cloud

## Definition

Die Hybrid Cloud kombiniert **On-Premise-Infrastruktur (oder Private Cloud) mit einer Public Cloud** und verbindet beide über eine sichere Netzwerkverbindung. Daten und Anwendungen können so je nach Bedarf zwischen den beiden Welten verschoben werden – zum Beispiel sensible Daten On-Prem behalten, aber Rechenleistung für Lastspitzen aus der Public Cloud dazuholen.

Das gibt Unternehmen das **Beste aus beiden Welten**: Kontrolle wo nötig, Flexibilität wo möglich.

## Eigenschaften

- Kombination aus mindestens zwei Umgebungen (z.B. On-Prem + Public Cloud)
- Sensible Daten können lokal bleiben, während unkritische Workloads in die Cloud ausgelagert werden
- Ermöglicht "Cloud Bursting": bei Lastspitzen kurzfristig Public-Cloud-Ressourcen zuschalten
- Höhere Komplexität, da mehrere Umgebungen verwaltet und verbunden werden müssen
- Guter Kompromiss zwischen Sicherheit/Kontrolle und Skalierbarkeit/Kosten

## Beispiele

- Microsoft Azure Arc / Azure Stack HCI
- AWS Outposts
- VMware Cloud on AWS
