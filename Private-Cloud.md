# Private Cloud

## Definition

Eine Private Cloud funktioniert technisch wie eine normale Cloud (Virtualisierung, Self-Service, Skalierbarkeit), wird aber **exklusiv für ein einzelnes Unternehmen** betrieben. Sie kann entweder im eigenen Rechenzentrum des Unternehmens stehen oder von einem externen Anbieter gehostet werden – wichtig ist, dass die Ressourcen nicht mit anderen Kunden geteilt werden.

Man bekommt also die Vorteile der Cloud-Technologie (Flexibilität, Automatisierung), aber ohne das "Teilen" der Public Cloud.

## Eigenschaften

- Ressourcen werden nur von einem Unternehmen genutzt (Single-Tenant)
- Höhere Kontrolle und Sicherheit als bei der Public Cloud
- Kann selbst betrieben oder von einem Anbieter gehostet werden
- Höhere Kosten als Public Cloud, da keine Skaleneffekte mit anderen Kunden
- Oft eingesetzt, wenn strenge Compliance- oder Datenschutzanforderungen bestehen

## Beispiele

- VMware Private Cloud
- Microsoft Azure Stack
- Eigene OpenStack-Installation im firmeneigenen Rechenzentrum
