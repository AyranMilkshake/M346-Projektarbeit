# Private Cloud

## Definition

Eine **Private Cloud** ist eine Cloud-Infrastruktur, die exklusiv für ein einzelnes Unternehmen betrieben wird. Sie kann entweder im eigenen Rechenzentrum des Unternehmens (OnPremise) oder von einem externen Dienstleister gehostet werden – entscheidend ist nicht der physische Standort, sondern dass die Ressourcen **nicht** mit anderen Kunden geteilt werden.

Im Vergleich zur Public Cloud entspricht die Private Cloud eher einem Einfamilienhaus: Man hat das ganze Grundstück für sich allein, auch wenn ein externer Hausverwalter sich um die Technik kümmert.

## Typische Merkmale

- Nur ein einziger "Mandant" (Unternehmen) nutzt die Ressourcen
- Höhere Kontrolle über Sicherheit, Datenschutz und Konfiguration als bei der Public Cloud
- Kann individuell an die Bedürfnisse des Unternehmens angepasst werden
- Meist teurer als eine Public Cloud, da die Ressourcen nicht mit anderen geteilt werden

## Vor- und Nachteile

**Vorteile:** hohe Sicherheit und Kontrolle, gut geeignet für sensible Daten oder strenge regulatorische Anforderungen

**Nachteile:** höhere Kosten, geringere Skalierbarkeit als bei einer Public Cloud, eventuell eigenes Fachpersonal nötig

## Beispiele

- VMware Private Cloud
- OpenStack-basierte Private Clouds
- Von einem Provider dediziert gehostete Infrastruktur für ein einzelnes Unternehmen
