# Public Cloud

## Definition

Eine **Public Cloud** ist eine Cloud-Umgebung, deren Infrastruktur einem breiten Publikum – also vielen verschiedenen Kunden gleichzeitig – gehört und von einem externen Anbieter betrieben wird. Die physischen Ressourcen (Server, Speicher, Netzwerk) werden von mehreren Kunden gemeinsam genutzt (Multi-Tenancy), die einzelnen Kunden sind dabei aber logisch voneinander getrennt und bemerken die anderen Mieter nicht.

Man kann sich das wie ein Mehrfamilienhaus vorstellen: Viele Parteien teilen sich dasselbe Gebäude und dieselbe Infrastruktur (Heizung, Treppenhaus), haben aber jeweils ihre eigene, abgeschlossene Wohnung.

## Typische Merkmale

- Ressourcen werden über das Internet öffentlich bereitgestellt
- Abrechnung nach Nutzung (pay-per-use), keine eigenen Investitionen in Hardware nötig
- Sehr hohe und schnelle Skalierbarkeit, da der Anbieter riesige Kapazitäten bereithält
- Wartung, Sicherheit und Updates der Infrastruktur übernimmt der Anbieter

## Vor- und Nachteile

**Vorteile:** geringe Einstiegskosten, hohe Flexibilität, kein eigener Betriebsaufwand

**Nachteile:** weniger Kontrolle über physischen Speicherort der Daten, potenzielle Compliance-Herausforderungen

## Beispiele

- AWS (Amazon Web Services)
- Microsoft Azure
- Google Cloud Platform
