# SaaS – Software as a Service

## Definition

Bei **SaaS** bezieht man eine fertige Anwendung direkt über das Internet, meist per Browser oder App. Der Anbieter betreibt und wartet die komplette Infrastruktur, Plattform und Software. Der Kunde muss nichts installieren, konfigurieren oder aktualisieren – er nutzt die Software einfach, in der Regel gegen eine monatliche oder jährliche Abo-Gebühr.

In der Wohnungs-Analogie entspricht SaaS einem Hotelzimmer: Man bezahlt für die Nutzung, muss sich aber um nichts kümmern – weder um Möbel noch um Reinigung oder Reparaturen.

## Wer verwaltet was?

| Schicht | Verantwortung |
|---|---|
| Anwendungen / Daten | Anbieter (Kunde verwaltet nur seine eigenen Daten/Inhalte) |
| Laufzeitumgebung / Middleware | Anbieter |
| Betriebssystem | Anbieter |
| Virtualisierung | Anbieter |
| Server / Storage / Netzwerk (Hardware) | Anbieter |

## Typische Merkmale

- Sofort einsatzbereit, keine Installation nötig
- Zugriff von überall über den Browser möglich
- Wenig bis keine technische Verwaltung durch den Kunden
- Weniger Individualisierungsmöglichkeiten als bei IaaS oder PaaS

## Beispiele

- Microsoft 365 / Google Workspace
- Salesforce
- Dropbox, Slack
