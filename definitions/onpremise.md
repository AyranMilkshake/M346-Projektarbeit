# OnPremise

## Definition

**OnPremise** (auch "On-Prem") bezeichnet den klassischen Betrieb von IT-Infrastruktur und Software im eigenen Haus, also im firmeneigenen Serverraum oder Rechenzentrum. Das Unternehmen kauft die Hardware selbst, installiert die Software und ist vollständig für Betrieb, Wartung, Sicherheit und Updates verantwortlich – im Gegensatz zur Cloud, wo diese Aufgaben ganz oder teilweise an einen externen Anbieter ausgelagert werden.

## Wer verwaltet was?

Bei OnPremise liegt **die gesamte Verantwortung** beim Unternehmen selbst:

| Schicht | Verantwortung |
|---|---|
| Anwendungen / Daten | Unternehmen |
| Laufzeitumgebung / Middleware | Unternehmen |
| Betriebssystem | Unternehmen |
| Virtualisierung | Unternehmen |
| Server / Storage / Netzwerk (Hardware) | Unternehmen |

## Vor- und Nachteile

**Vorteile**
- Volle Kontrolle über Daten, Hardware und Sicherheitsmassnahmen
- Keine Abhängigkeit von einem externen Anbieter oder dessen Internetverbindung
- Wichtig, wenn strenge Compliance- oder Datenschutzvorgaben eine Datenhaltung im eigenen Land/Haus verlangen

**Nachteile**
- Hohe Anfangsinvestitionen (Hardware, Lizenzen, Räumlichkeiten)
- Eigenes Fachpersonal für Betrieb und Wartung nötig
- Skalierung ist langsamer und aufwändiger als in der Cloud
